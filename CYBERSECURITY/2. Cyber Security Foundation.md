## Section 1: Security Principles

#### 1.1 The CIA Triad (Deep Dive)
**Confidentiality:**
   •	Keeping data secret
   •	Encryption
   •	Access controls
   •	Data classification
**Integrity:**
   •	Keeping data accurate
   •	Hashing
   •	Digital signatures
   •	Version control
**Availability:**
   •	Keeping data accessible
   •	Redundancy
   •	Disaster recovery
   •	Business continuity
  
#### 1.2 Additional Security Principles
**AAA:**
   •	Authentication → Who are you?
   •	Authorization → What can you do?
   •	Accounting → What did you do?
**Non-Repudiation:**
   •	Cannot deny actions
   •	Digital signatures
   •	Audit logs
**Least Privilege:**
   •	Give minimum access needed
   •	Reduce attack surface
   •	Limit damage
**Defense in Depth:**
   •	Multiple layers of security
   •	Physical, network, host, application, data
   
#### 1.3 Security Frameworks
**NIST Cybersecurity Framework:**
   1.	Identify
   2.	Protect
   3.	Detect
   4.	Respond
   5.	Recover
**ISO 27001:**
   •	Information Security Management
   •	International standard
   •	Risk-based approach
**CIS Controls:**
   •	Top 20 critical controls
   •	Practical implementation
   •	Prioritised actions

## Section 2: Security Tools

#### 2.1 Network Scanning
**Nmap:**
   •	Port scanning
   •	Service detection
   •	OS detection
   •	Network mapping
**Basic Nmap Commands:**

nmap -sP 192.168.1.0/24     # Ping scan
nmap -sS 192.168.1.1        # SYN scan
nmap -sV 192.168.1.1        # Version detection
nmap -O 192.168.1.1         # OS detection
nmap -A 192.168.1.1         # Aggressive scan

#### 2.2 Vulnerability Scanning
**OpenVAS:**
   •	Vulnerability scanner
   •	Vulnerability database
   •	Comprehensive scanning
   •	Reporting
**Nessus:**
   •	Commercial scanner
   •	More comprehensive
   •	Compliance scanning
   •	Professional reports
   
#### 2.3 Network Monitoring
**Wireshark:**
   •	Packet capture
   •	Protocol analysis
   •	Traffic inspection
   •	Troubleshooting
**Basic Wireshark Filters:**

http                     # HTTP traffic
tcp.port == 443          # HTTPS traffic
ip.addr == 192.168.1.1   # Specific IP
tcp.flags.syn == 1       # SYN packets

## Section 6: Cryptography

#### 6.1 Encryption Basics
**Symmetric Encryption:**
   •	Same key for encryption/decryption
   •	Fast
   •	Examples: AES, DES, RC4
**Asymmetric Encryption:**
   •	Public/private key pairs
   •	Slower
   •	Examples: RSA, ECC
   
#### 6.2 Hashing
**Purpose:**
   •	Data integrity
   •	Password storage
   •	Digital signatures
**Common Hash Functions:**
   •	MD5 (weak)
   •	SHA-1 (weak)
   •	SHA-256
   •	SHA-512
   
#### 6.3 Digital Certificates
**Certificate Components:**
   •	Subject
   •	Issuer
   •	Public Key
   •	Expiration
   •	Signature
**Certificate Use Cases:**
   •	HTTPS
   •	Code signing
   •	Email encryption
