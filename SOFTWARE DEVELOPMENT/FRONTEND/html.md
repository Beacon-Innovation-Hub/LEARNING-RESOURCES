# 4. HTML Accessibility

**Level:** 🟡 Intermediate → 🔴 Advanced

Accessibility is a core requirement of professional web development.

### 📚 Required Documentation

**[MDN — Web Accessibility](https://developer.mozilla.org/en-US/docs/Web/Accessibility)**

**[MDN — HTML: A Good Basis for Accessibility](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Accessibility/HTML)**

### 🎯 Learning Objectives

Understand:

- Semantic HTML and accessibility
- Alternative text
- Accessible links
- Accessible forms
- Keyboard accessibility
- Focus management
- Heading hierarchy
- Accessible tables
- Native HTML controls
- ARIA fundamentals
- Screen-reader considerations

### 🧪 Practice

Audit one of your previous HTML projects for accessibility problems.

Document the problems you identify and correct them using semantic/native HTML wherever possible.

# 6. Professional HTML

**Level:** 🔴 Advanced

At this stage, the objective is no longer simply knowing HTML tags.

The objective is producing **standards-compliant, maintainable, accessible and production-quality HTML.**

### 📚 Primary Documentation

**[MDN Web Docs — HTML](https://developer.mozilla.org/en-US/docs/Web/HTML/)**

**[WHATWG — HTML Living Standard](https://html.spec.whatwg.org/)**

### 🎯 Advanced Topics

Study and apply:

- Professional document structure
- Global attributes
- Semantic content models
- `<picture>`
- `srcset`
- Responsive images
- `<audio>` and `<video>`
- `<iframe>`
- `<details>` and `<summary>`
- `<dialog>`
- `<template>`
- `data-*` attributes
- Metadata
- Advanced forms and validation
- Accessibility
- Standards-compliant markup
- Progressive enhancement
