## Browser Compatibility

For modern features ask:

``` text
Which browsers must be supported?
What happens if the feature is unsupported?
Is a fallback needed?
Can progressive enhancement be used?
```

## BIH Scenario --- CSS Technical Audit

The BIH website has accumulated duplicated declarations, deeply nested
selectors, `!important`, fixed dimensions and inconsistent breakpoints.

Audit:

-   duplicated CSS
-   unused rules
-   specificity conflicts
-   overflow
-   inaccessible focus states
-   animation problems
-   repeated magic numbers

Document each issue as:

``` text
Problem
Evidence
Impact
Correction
Validation
```

## Level 4 Challenge

Refactor a BIH interface to use maintainable selectors, responsive
components, accessible states, modern CSS and justified animation.
