## Section 1: Computer Fundamentals

### 1.1 What is a Computer?

A computer is an electronic device that processes data. It takes input, processes it, and produces output.

Key Components:

Component                       	Function

CPU (Central Processing Unit)    	The brain of the computer - processes instructions

RAM (Random Access Memory)	      Temporary storage for active programs and data

Storage (HDD/SSD)               	Permanent storage for files and programs

Motherboard	                      Connects all components together

Power Supply                     	Provides power to all components

**How Computers Process Data:**

  1.	Input → User provides data (keyboard, mouse, network)
  2.	Processing → CPU processes the data
  3.	Storage → Data is saved to storage
  4.	Output → Results are displayed (screen, printer)
  	
### 1.2 Binary and Data Representation
Computers work with binary data - 1s and 0s.

**Binary Basics:**

  •	Bit: A single 1 or 0
  
  •	Byte: 8 bits
  
  •	Kilobyte (KB): 1024 bytes
  
  •	Megabyte (MB): 1024 KB
  
  •	Gigabyte (GB): 1024 MB
  
  •	Terabyte (TB): 1024 GB
  
**Data Types:**

  •	Text: Stored as ASCII or Unicode
  
  •	Images: Stored as pixels
  
  •	Audio: Stored as sound waves
  
  •	Video: Combination of images and audio
  
**Why Binary Matters in Security:**

•	Understanding how data is stored helps with:

    o	File analysis
    
    o	Malware analysis
    
    o	Data recovery
    
    o	Low-level security tasks

## Section 2: Operating Systems

### 2.1 What is an Operating System?

An operating system (OS) is software that manages computer hardware and provides services for computer programs.

Main Functions:

  •	Process management

  •	Memory management

  •	File system management

  •	Device management

  •	Security and access control

### 2.2 Windows Operating System

**Key Features:**

  •	Graphical User Interface (GUI)
  
  •	Widely used in enterprises
  
  •	Common target for attackers
  
**Windows Security Concepts:**

  •	User accounts and permissions
  
  •	File system permissions (NTFS)
  
  •	Windows Registry
  
  •	Active Directory
  
  •	Group Policy
  
  •	Windows Defender
  
### 2.3 Linux Operating System

**Key Features:**

  •	Open source
  
  •	Command-line focused
  
  •	Widely used in servers
  
  •	Common for security tools
  
**Linux Security Concepts:**

  •	User permissions (rwx)
  
  •	sudo access
  
  •	File system structure
  
  •	Package managers
  
  •	Shell scripting
  
  •	Firewall (iptables)
  
### 2.4 macOS Operating System

**Key Features:**

  •	Unix-based
  
  •	User-friendly interface
  
  •	Growing in enterprise
  
  •	Strong security features
  
**macOS Security Concepts:**

  •	System Integrity Protection (SIP)
  
  •	FileVault encryption
  
  •	Gatekeeper
  
  •	App sandboxing

## Section 3: Networking Basics

### 3.1 What is a Network?

A network is two or more computers connected to share resources and communicate.
Network Types:

  •	LAN (Local Area Network) - Small area like office
  
  •	WAN (Wide Area Network) - Large area like internet
  
  •	MAN (Metropolitan Area Network) - City-wide
  
  •	PAN (Personal Area Network) - Personal devices

## Section 4: Command Line Basics

### 4.1 Why Command Line Matters in Security

  •	Faster than GUI
  
  •	Automatable
  
  •	More powerful
  
  •	Required for many security tools
  
  •	Essential for incident response
  
### 4.2 Windows Command Prompt

**Basic Commands:**

**Navigation**

cd       - Change directory

dir      - List directory contents

mkdir    - Create directory

rmdir    - Remove directory

**File Operations**

copy     - Copy files

move     - Move files

del      - Delete files

type     - Display file contents

**System Information**

ipconfig - Network configuration

systeminfo - System information

tasklist - Running processes

netstat  - Network connections

**Network Commands**

ping     - Test connectivity

tracert  - Trace route

nslookup - DNS lookup

net      - Network services

### 5.2 Authentication

**Three Factors:**
 1.	Something you know (password)
 2.	Something you have (smart card)
 3.	Something you are (fingerprint)
 4.	
**Authentication Types:**

  •	Single Factor
  
  •	Two Factor
  
  •	Multi Factor
  
  •	Biometric
  
### 5.3 Authorization

**Access Control Models:**

 •	DAC (Discretionary) - Owner decides
 
 •	MAC (Mandatory) - System decides
 
 •	RBAC (Role-Based) - Role decides
 
### 5.4 Common Threats

  •	Viruses: Self-replicating code

  •	Worms: Self-replicating across networks

  •	Trojan Horses: Disguised as legitimate

  •	Ransomware: Encrypts data for ransom

  •	Phishing: Deceptive emails

  •	DDoS: Overwhelming attacks

  •	Malware: Malicious software

  •	Social Engineering: Human manipulation

### 5.5 Security Controls

**Physical Controls:**

    •	Locks, Guards, CCTV
  
**Administrative Controls:**

    •	Policies, Procedures, Training
    
**Technical Controls:**

    •	Firewalls, Antivirus, Encryption
