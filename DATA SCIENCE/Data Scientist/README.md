Core vs Advanced

Levels 1--4 form the core Data Scientist pathway. A learner should
be able to frame problems, analyse data, apply statistical reasoning,
build models and evaluate them correctly.

Levels 5--6 extend the pathway into modern AI systems and production
machine learning.

Watching videos is not evidence of competence. Complete the exercises,
document decisions, explain limitations, and produce work that can be
technically reviewed.
