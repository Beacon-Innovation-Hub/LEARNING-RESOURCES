## Practice Challenge — Registration Form

Build a registration form containing:

- [ ] Full name
- [ ] Email address
- [ ] Password
- [ ] Date of birth
- [ ] Dropdown
- [ ] Radio buttons
- [ ] Checkboxes
- [ ] Text area
- [ ] Submit button

Use appropriate:

- Labels
- Input types
- `name` attributes
- Native validation
- Required fields

### Additional Challenge

Test the form without using a mouse. Check whether each field can be understood and reached using the keyboard.

---

## Review Questions

1. Why is `<label>` important?
2. What is the purpose of the `name` attribute?
3. What is the difference between GET and POST?
4. Why should suitable input types be used?
5. What validation can HTML perform without JavaScript?
