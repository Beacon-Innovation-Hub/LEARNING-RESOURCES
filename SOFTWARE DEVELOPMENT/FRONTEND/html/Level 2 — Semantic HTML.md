## Practice Challenge

Take a webpage that relies heavily on `<div>` elements and restructure it using appropriate semantic HTML.

### Before

```html
<div>
  <div>Website Name</div>
  <div>Navigation...</div>
</div>

<div>
  <div>Article...</div>
</div>
```

### Your Task

Decide which semantic elements should replace the generic containers.

Do not replace every `<div>` automatically. A `<div>` remains appropriate when no semantic element accurately describes the content.

---

## Review Questions

1. What makes an HTML element semantic?
2. When should `<article>` be used instead of `<section>`?
3. Why should a page normally have a `<main>` element?
4. When is `<div>` still appropriate?
5. How can semantic HTML help accessibility and maintainability?
