## BIH Labs

### Lab 1 --- Participant Profile Card

Build a Beacon Innovation Hub participant card with a profile image,
name, technical pathway, biography, skills and button.

### Lab 2 --- Navigation

Create `Home`, `About`, `Learning Resources`, `Projects`, and
`Community` links with spacing and hover states.

### Lab 3 --- Project Card

Build a BIH project card with image, project name, technical team,
status and action button.

## Level 1 Challenge

Build a reusable **BIH Learning Resource Card** demonstrating the Box
Model, typography, spacing, classes, borders, hover states, cascade and
readable CSS organization.
