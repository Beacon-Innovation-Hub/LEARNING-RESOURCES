# Level 6 — Professional HTML

> Produce standards-conscious, maintainable, accessible and production-quality HTML.

**Difficulty:** Advanced

[← Previous Level](<05 - Level 5 - HTML for SEO.md>) · [Final Project →](<07 - Final HTML Practice Project.md>)

---

## Objective

At this stage, the objective is no longer simply knowing HTML tags.

The objective is producing:

> **Standards-compliant, maintainable, accessible and production-quality HTML.**

---

## Primary Documentation

**[MDN Web Docs — HTML](https://developer.mozilla.org/en-US/docs/Web/HTML/)**

**[WHATWG — HTML Living Standard](https://html.spec.whatwg.org/)**

Use documentation as a normal part of development rather than attempting to memorize the entire HTML specification.

## Practice — Professional Page Refactor

Select one of your earlier HTML projects and refactor it as if it were going into production.

Review:

### Structure
- [ ] Correct document structure
- [ ] Semantic landmarks
- [ ] Logical heading hierarchy
- [ ] Maintainable markup

### Media
- [ ] Responsive image strategy
- [ ] Appropriate image alternatives
- [ ] Correct media elements

### Forms
- [ ] Labels
- [ ] Input types
- [ ] Native validation
- [ ] Accessible instructions

### Metadata
- [ ] Page title
- [ ] Meta description
- [ ] Appropriate metadata
- [ ] SEO-conscious structure

### Quality
- [ ] No unnecessary markup
- [ ] No obvious invalid nesting
- [ ] Native elements preferred where appropriate
- [ ] HTML remains understandable without CSS
