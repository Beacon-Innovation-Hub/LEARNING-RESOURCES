## Required Competence

### Layout

-   [ ] Mobile-first
-   [ ] Flexbox
-   [ ] Grid
-   [ ] Responsive navigation
-   [ ] Responsive cards/images/typography

### CSS Engineering

-   [ ] Custom properties
-   [ ] Reusable components
-   [ ] Controlled specificity
-   [ ] Clear stylesheet organization
-   [ ] Consistent spacing and typography

### Interaction

-   [ ] Hover states
-   [ ] Focus states
-   [ ] Active/current states
-   [ ] Form states
-   [ ] Appropriate transitions
-   [ ] At least one justified animation

### Accessibility

-   [ ] Keyboard-visible focus
-   [ ] Reduced-motion consideration
-   [ ] Readable contrast
-   [ ] Zoom/resizing testing
-   [ ] Interface remains usable without hover

# Technical Defence

Be prepared to answer:

1.  Why Grid instead of Flexbox?
2.  Why this breakpoint?
3.  What determines this element's width?
4.  Why is one rule overriding another?
5.  Explain this selector's specificity.
6.  What happens at 320px?
7.  What happens when text doubles in length?
8.  Why use `rem` instead of `px`?
9.  How is keyboard focus represented?
10. How is reduced motion handled?
11. Which CSS can be removed?
12. How would you make this component reusable?
