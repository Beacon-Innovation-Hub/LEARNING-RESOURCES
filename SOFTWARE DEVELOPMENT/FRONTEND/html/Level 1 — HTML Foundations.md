# Level 1 — HTML Foundations

> Learn the structure and core elements used to create HTML documents.

**Difficulty:** Beginner

[← HTML Roadmap](README.md) · [Next Level →](Level%202%20—%20Semantic%20HTML.md)

---

## Learning Objectives

Develop an understanding of:

- [ ] HTML document structure
- [ ] Elements, tags and attributes
- [ ] Headings and paragraphs
- [ ] Links and navigation
- [ ] Images
- [ ] Lists
- [ ] Tables
- [ ] Basic forms
- [ ] Page structure

## Practice

Create a simple HTML page containing:

- A valid HTML document structure
- Page title
- Main heading
- Multiple heading levels
- Paragraphs
- Ordered and unordered lists
- Internal and external links
- At least one image with alternative text
- A table
- A basic form

## Level Completion Checklist

- [ ] I can create an HTML document without copying a template.
- [ ] I understand the purpose of `<!doctype html>`.
- [ ] I understand `<html>`, `<head>` and `<body>`.
- [ ] I can use headings correctly.
- [ ] I can create links and images.
- [ ] I can create lists and tables.
- [ ] I understand basic forms.
- [ ] I completed the practice page.
- [ ] I can explain my markup.
