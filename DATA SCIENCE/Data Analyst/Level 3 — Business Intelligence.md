# Level 3 — Business Intelligence

**Classification:** Intermediate Analyst  
**Goal:** Build reliable analytical models and interactive reports using Power BI, Power Query, data relationships and DAX.

## Level 3 Outcomes

By the end of this level, the participant should be able to:

- [ ] Import and transform data with Power Query
- [ ] Define appropriate data types
- [ ] Create and validate table relationships
- [ ] Distinguish fact and dimension tables
- [ ] Build a basic star schema
- [ ] Create reusable DAX measures
- [ ] Explain calculated columns versus measures
- [ ] Use filter context appropriately
- [ ] Build interactive Power BI reports
- [ ] Use slicers, filters, cards, tables and charts effectively

## Level 3 Competence Assessment

The participant should build a Power BI solution from multiple related tables that includes:

- A documented data model
- Power Query transformations
- Correct relationships and cardinality
- Core DAX measures
- KPI cards
- At least two analytical report pages
- Appropriate filters and slicers
- Validation of key totals against source data

**Progression rule:** Visual appearance alone is not sufficient. The participant must defend the correctness of the model, measures and transformations.
