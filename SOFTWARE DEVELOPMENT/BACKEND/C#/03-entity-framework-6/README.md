## 1. Introduction & Overview

Entity Framework 6 (EF6) is an Object-Relational Mapping (ORM) framework that allows C# applications to work with relational databases using C# objects and classes.

### Object-Relational Mapping (ORM)

ORM creates a relationship between objects in a C# application and tables in a relational database.

For example:

```text
C# Class              Database Table

Student        →      Students
Id             →      Id
Name           →      Name
Age            →      Age
