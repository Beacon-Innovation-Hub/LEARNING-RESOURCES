## 👋 Welcome to the Data Field

The **Beacon Innovation Hub Data Learning Path** introduces learners to the technologies, methods, and problem-solving approaches used to work with data professionally.

The pathway is divided into three major specialisations:

- 🏗️ **Data Engineering** — builds the systems that collect, transform, store, and deliver data.
- 📊 **Data Analysis** — investigates data and turns it into useful information for decision-making.
- 🧠 **Data Science** — uses statistics, mathematics, experimentation, and machine learning to model patterns and support prediction.

Although these roles have different responsibilities, they share important foundations. For this reason, learners begin with a **common Python for Data course** before progressing into their chosen specialist pathway.

# 🔄 You Are Not Locked Into One Path

The three pathways overlap.

A Data Analyst may later learn machine learning.

A Data Scientist still needs SQL and data-cleaning skills.

A Data Engineer needs Python and SQL.

A Data Scientist benefits from understanding pipelines.

A Data Analyst benefits from understanding database design.

A Data Engineer benefits from understanding how analysts and scientists consume data.

The repository therefore follows a **T-shaped learning philosophy**:

```text
                 BROAD DATA KNOWLEDGE
────────────────────────────────────────────────
 Python • SQL • Data • Statistics • Git • Quality
                         │
                         │
                         ▼
                  SPECIALISATION
                         │
                         │
                         ▼
                Deep Role Skills
```
