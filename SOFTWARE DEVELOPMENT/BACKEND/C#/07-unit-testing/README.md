## 1. Introduction to Unit Testing

Unit testing is the process of testing small, individual pieces of code to verify that they behave as expected.

A unit can be:

- A method
- A class
- A function
- A small piece of business logic

The goal is to test these components independently.

Application Code
       ↓
   Unit Test
       ↓
Expected Result
       ↓
