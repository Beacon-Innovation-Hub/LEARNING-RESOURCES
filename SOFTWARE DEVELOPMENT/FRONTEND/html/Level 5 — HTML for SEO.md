## Practice — SEO HTML Audit

Take a previous multi-section page and review its HTML.

Check:

- [ ] Descriptive `<title>`
- [ ] Useful meta description
- [ ] Logical heading hierarchy
- [ ] Semantic page structure
- [ ] Descriptive internal links
- [ ] Meaningful image alternatives
- [ ] Appropriate canonical reference where applicable
- [ ] Useful page metadata
- [ ] Crawlable important content

### Metadata Practice

Create an appropriate `<head>` for a fictional Beacon Innovation Hub article page.

Explain the purpose of each important metadata element you include.

---

## Important Principle

SEO-conscious HTML should improve the structure and meaning of a page rather than encourage keyword stuffing or misleading metadata.

```text
Useful Content
      +
Clear Structure
      +
Meaningful Metadata
      +
Accessible HTML
```
