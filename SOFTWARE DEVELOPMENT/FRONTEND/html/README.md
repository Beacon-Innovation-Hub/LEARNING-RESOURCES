## How to Use This Path

For every level:

1. Watch the recommended lesson.
2. Read the required documentation.
3. Reproduce the concepts yourself.
4. Complete the practice activity.
5. Review your work against the checklist.
6. Continue only when you can explain and apply the concepts independently.

> The objective is not to memorize HTML tags. The objective is to create structured, semantic, accessible and standards-conscious web documents.
