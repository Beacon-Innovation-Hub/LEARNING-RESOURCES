## 1. Introduction & Overview

CI/CD is a set of practices used to automate the process of building, testing, and delivering software.

The general software delivery process can be represented as:

```text
Developer
    ↓
Write Code
    ↓
Git Repository
    ↓
Build
    ↓
Test
    ↓
Deploy
    ↓
Production
