## Section 3: Scanning and Enumeration

### 3.1 Nmap Deep Dive

**Installation:**

**Ubuntu/Debian**

  sudo apt-get install nmap

**Windows**

  Download from nmap.org

**macOS**

  brew install nmap

**Basic Scans:**

  nmap -sP 192.168.1.0/24    # Ping scan (find hosts)
  
  nmap -sS 192.168.1.1       # SYN scan (stealth)
  
  nmap -sT 192.168.1.1       # TCP connect scan
  
  nmap -sU 192.168.1.1       # UDP scan
  
  nmap -O 192.168.1.1        # OS detection
  
  nmap -sV 192.168.1.1       # Version detection
  
  nmap -A 192.168.1.1        # Comprehensive

**Port Scanning Options:**

  nmap -p 80,443 192.168.1.1      # Specific ports
  
  nmap -p 1-1000 192.168.1.1      # Port range
  
  nmap -p- 192.168.1.1            # All ports
  
  nmap --top-ports 100 192.168.1.1 # Top ports

**Output Formats:**

  nmap -oN output
