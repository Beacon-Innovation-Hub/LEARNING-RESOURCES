# Penetration Tester

**Attack • Test • Exploit • Report**

Welcome to the Penetration Tester pathway. This specialisation focuses on ethical hacking - finding and exploiting vulnerabilities to help organisations improve their security.

## About This Pathway
Penetration testers, also called ethical hackers, are hired to find security weaknesses before attackers do. They think like attackers but work defensively.

What You Will Learn:

  •	Ethical hacking techniques
  
  •	Penetration testing methodology
  
  •	Web application testing
  
  •	Network testing
  
  •	Reporting and communication

## Career Overview
**What Penetration Testers Do:**

  •	Conduct authorized security tests
  
  •	Find vulnerabilities in systems
  
  •	Exploit vulnerabilities to demonstrate risk
  
  •	Write detailed reports
  
  •	Recommend fixes
  
**Common Job Titles:**

  •	Penetration Tester
  
  •	Ethical Hacker
  
  •	Security Consultant
  
  •	Red Team Operator
  
  •	Application Security Tester
  
**Industries:**

  •	Consulting firms
  
  •	Banks and finance  
  
  •	Government
  
  •	Technology companies
  
  •	Any organization with security needs
  
**Skills Needed:**

  •	Technical curiosity
  
  •	Problem-solving
  
  •	Persistence
  
  •	Attention to detail
  
  •	Communication skills
  
  •	Ethical mindset

## Ethics and Legality

**Important:**

  •	Always have written authorization
  
  •	Stay within scope
  
  •	Protect sensitive data
  
  •	Report findings responsibly
  
**Legal Framework:**

  •	Computer Fraud and Abuse Act
  
  •	Data protection laws
  
  •	Contractual obligations
  
**Ethical Principles:**

  •	Do no harm
  
  •	Protect client data
  
  •	Be transparent
  
  •	Act professionally

## How to Succeed
  
  1.	Practice constantly: Security testing is a practical skill
  2.	Stay curious: Always learn new techniques
  3.	Think like an attacker: Understand the enemy
  4.	Communicate well: Reports matter
  5.	Be ethical: Trust is everything
  6.	Never give up: Persistence is key
  7.	Keep learning: The threat landscape changes
