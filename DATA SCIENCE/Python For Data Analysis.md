# 🧩 Data Cleaning Challenge

Take a deliberately messy dataset containing:

- Missing values
- Duplicate rows
- Incorrect data types
- Inconsistent text
- Invalid values
- Incorrect dates
- Outliers

Document:

1. What problem you discovered.
2. Why it is a problem.
3. How you corrected it.
4. Why you selected that correction.
5. How you verified the transformation.

Do not silently clean the dataset.

A professional data practitioner should be able to explain every
transformation.
