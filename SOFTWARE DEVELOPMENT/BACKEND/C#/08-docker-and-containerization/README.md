## 1. Introduction to Docker

Docker is a platform used to package applications and their dependencies into containers.

Instead of installing and configuring an application manually on every computer, Docker allows the application to run inside a consistent environment.

```text
Application
     ↓
Dependencies
     ↓
Docker Image
     ↓
Docker Container
     ↓
Running Application
