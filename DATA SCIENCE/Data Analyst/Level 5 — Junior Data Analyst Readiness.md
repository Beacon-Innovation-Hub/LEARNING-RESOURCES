# Level 5 — Junior Data Analyst Readiness

**Classification:** Junior Readiness / Capstone  
**Goal:** Demonstrate independent end-to-end competence using unfamiliar organisational data.

## Level 5 Outcomes

A participant at this level should be able to independently:

- [ ] Clarify a business problem and identify stakeholders
- [ ] Acquire and understand unfamiliar data
- [ ] Clean, transform and validate data
- [ ] Query relational data using SQL
- [ ] Apply appropriate statistical analysis
- [ ] Build an analytical data model
- [ ] Develop an interactive business-intelligence report
- [ ] Define meaningful KPIs
- [ ] Explain findings and limitations
- [ ] Recommend appropriate next actions
- [ ] Structure work professionally in GitHub
- [ ] Defend analytical decisions in a technical review

## Final Competence Assessment

The final assessment should test the entire analyst workflow rather than isolated tool knowledge.

The participant should submit:

- `README.md` explaining the business problem and approach
- Raw and cleaned data, where sharing is permitted
- Data-quality and transformation documentation
- Spreadsheet analysis
- SQL scripts
- Statistical analysis
- Power BI report
- Exported charts or report outputs
- Findings and recommendations
- Limitations
- Validation evidence

### Technical Defence

After submission, the participant should defend the project before assessors. The defence should test:

- Why particular transformations were made
- How joins and calculations were validated
- Why particular statistics or visualizations were selected
- Whether the participant can reproduce key results
- Whether claims are supported by evidence
- What limitations could change the conclusion
- What the analyst would investigate next

Successful completion supports classification as a **BIH Junior Data Analyst**.

## 🏆 Portfolio Standard

Do not build a portfolio containing only screenshots.

Every project should explain:

```text
❓ Problem
    ↓
📥 Data
    ↓
🧹 Preparation
    ↓
🔎 Analysis
    ↓
📊 Visualization
    ↓
🧠 Findings
    ↓
🎯 Recommendations
    ↓
⚠️ Limitations
```

A reviewer should be able to understand:

- What problem did you solve?
- What data did you use?
- How did you prepare it?
- What did you discover?
- Why does the result matter?
- What are the limitations?

## 🚀 Completion

A developing Data Analyst should eventually be able to receive unfamiliar organisational data and independently:

```text
❓ Define the Question
        ↓
📥 Understand the Data
        ↓
🧹 Prepare & Validate
        ↓
🗄️ Query
        ↓
📐 Analyse
        ↓
📊 Visualize
        ↓
🧠 Interpret
        ↓
🎯 Recommend
        ↓
📢 Communicate
```

> **A Data Analyst's value is not determined by how many tools they know. It is determined by their ability to turn trustworthy evidence into information that supports better decisions.**
